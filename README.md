# Tool TL - CLOUD

Phần mềm quản lý, đồng bộ dữ liệu doanh nghiệp và tạo mã QR tự động.

## 🚀 Các tính năng chính
- **Quản lý dữ liệu công ty**: Tra cứu, lọc theo Mã số thuế / Tên công ty theo từng năm làm việc.
- **Phòng & User**: Quản lý và gán phòng ban, người phụ trách kèm tính năng gợi ý thông minh (Smart Autocomplete).
- **Sao chép USB**: Tự động định dạng và đồng bộ dữ liệu ra USB đích an toàn, tự động lưu thông tin bàn giao.
- **Đồng bộ Cloud / Server**: Dọn rác và đồng bộ dữ liệu một hoặc toàn bộ đơn vị lên hệ thống lưu trữ mạng.
- **Double Check**: Kiểm tra tự động liên kết OneDrive và dữ liệu mã số thuế.
- **Tạo mã QR Offline**: Tự động sinh mã QR từ danh sách dữ liệu Offline nhanh chóng.

## 🛠️ Hướng dẫn cài đặt & chạy
```bash
# Kích hoạt môi trường ảo
.\.venv\Scripts\Activate.ps1

# Chạy ứng dụng
```
